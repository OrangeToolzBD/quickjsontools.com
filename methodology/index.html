Methodology

Every tool on this site runs in your browser. The page loads the tool code from this site, and when you press a button, that code processes your input on your own device. The tools make no network requests with your input, do not store it, and do not send it to analytics. Results depend on what you paste, plus your computer’s clock for the time-based tools and its random number generator for UUIDs.

What runs where

  • Your browser: all parsing, formatting, converting, comparing, hashing and generating.
  • This site’s server: delivers the pages, the tool code and three vendored libraries. It receives nothing you type.
  • Google Analytics: page-view measurement only; see the privacy policy.

Third-party libraries

Three tools use open-source libraries. Each is a copy served from this site, not loaded from another host. If a copy is missing, the tool says the library is not loaded rather than failing silently.

Testing

The tool logic is covered by 32 automated tests with known answers. They include the MD5 test values from RFC 1321, the SHA-1 and SHA-256 hashes of “abc”, a UTF-8 Base64 round trip, URL-safe Base64 without padding, percent-encoding of reserved and non-ASCII characters, seconds and milliseconds timestamps, a UUIDv7 with a fixed time, JWT expiry checks, JSON error positions, line and structural diffs, CSV quoting, XML nesting errors, schema inference and cron schedules. The Base64, URL, epoch and hash vectors were computed independently with Node.js. The tests are run after every change to the tools.

Limits

  • The JWT decoder does not verify signatures, and decoded claims should not be trusted until your server verifies them.
  • The XML formatter checks tag nesting only; it does not validate against a DTD or schema.
  • The SQL formatter and HTML beautifier reformat code; they do not check that it is correct.
  • Large inputs are limited by your device’s memory and speed. The diff checker refuses very large comparisons, and the regex tester stops after 2 seconds.
  • MD5 and SHA-1 are provided for checksums only and must not be used for security.

Updates and corrections

There is no outside data to refresh. The tools and pages are reviewed when a cited standard or one of the libraries changes, and whenever a reader reports an error. Confirmed errors are fixed and a test is added. See the about page for how to report a problem.
