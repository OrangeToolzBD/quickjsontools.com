Case Converter

A case converter rewrites text in a different capitalization style with one click: UPPER, lower, Title Case, Sentence case, camelCase, PascalCase, snake_case, kebab-case or CONSTANT_CASE. For example, “hello world of code” becomes “Hello World of Code” in title case and helloWorldOfCode in camelCase. Conversion runs in your browser.

Updated September 20, 2026 · By Quick JSON Tools

How do I convert text to title case?

Paste your text and press Title Case. The tool lowercases everything, then capitalizes the first letter of each word, except short function words such as “of”, “the” and “and”, which stay lowercase unless they are the first or last word.

Worked examples:

InputTitle Case
hello world of codeHello World of Code
the lord of the ringsThe Lord of the Rings
what is it forWhat Is It For
NASA launches e-mail toolNasa Launches E-mail Tool

The last row shows the two limits to watch. Because the text is lowercased first, acronyms lose their capitals, so fix NASA, API or JSON by hand. Words are split on spaces only, so in a hyphenated word only the first part is capitalized.

Sentence case works the same way but capitalizes only the first letter of the text and the first letter after a period, exclamation mark or question mark: “hello. world! ok” becomes “Hello. World! Ok”. Proper nouns end up lowercase, so read the result before using it.

camelCase vs snake_case vs kebab-case

All three join several words into one identifier. camelCase capitalizes each word after the first, snake_case joins lowercase words with underscores, and kebab-case joins them with hyphens. Which you use depends on the language, framework or file format, so follow the convention already in your codebase.

The converter finds word boundaries at spaces, underscores, hyphens and a lowercase letter followed by a capital. That lets you convert between code styles directly: the test case turns helloWorldOfCode into hello_world_of_code, and “my-var_name here” becomes MyVarNameHere.

Two cases need a manual check:

  • Runs of capitals are not split: parseHTTPResponse becomes parse_httpresponse, not parse_http_response.
  • Punctuation is kept inside words, so “don’t stop” becomes a camelCase value containing an apostrophe, which is not a valid identifier. Remove punctuation first.

For JSON keys, convert the names here, then check the file in the JSON formatter.

Which words stay lowercase in title case?

This tool keeps these words lowercase in the middle of a title: a, an, and, as, at, but, by, for, in, nor, of, on, or, per, the, to, up, via, vs and yet. They are articles, short conjunctions and short prepositions. The first and last words are always capitalized, whatever they are.

Style guides do not fully agree on this list. They differ on details such as whether longer prepositions like “with”, “from” or “about” should be capitalized; this tool capitalizes them. If you follow a specific house style, check the result against it and adjust the few words that differ.

A few habits that avoid surprises:

  • Capitalize the word after a colon if your style requires it; the tool treats it like any other word.
  • Restore brand names with unusual capitals, such as iPhone or GitHub, after converting.
  • For headings in code or documentation, consider sentence case, which is easier to apply consistently.

Frequently asked questions

Why did my acronym turn lowercase?

Title Case and Sentence case lowercase the whole text before capitalizing, so NASA becomes Nasa and API becomes Api. The tool cannot tell an acronym from a word typed in capitals. Restore acronyms and brand names by hand after converting, or convert the surrounding text and leave those words as they were.

Can I convert camelCase to snake_case?

Yes. Paste the camelCase name and press snake_case; the tool splits at each change from a lowercase letter or digit to a capital, so helloWorldOfCode becomes hello_world_of_code. Names with runs of capitals, such as HTTPServer, are not split and need a manual fix, as does any name containing punctuation.

Is my text stored or sent anywhere?

No. The conversion happens in JavaScript in your browser, and nothing you type is uploaded, logged or saved, which you can check in the Network tab of your browser’s developer tools. The methodology page describes what each tool runs and where.
