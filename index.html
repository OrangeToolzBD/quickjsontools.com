Format, validate & explore JSON

The core JSON toolkit: format, validate, diff, view, stringify and generate schemas.

JSON Formatter & Validator

Format, minify and validate JSON with the exact line and column of any error. Runs entirely in your browser; nothing you paste is uploaded.

JSON Validator

Validate JSON and see the exact line and column of any syntax error. Runs in your browser, so the data you paste never leaves your machine.

JSON Viewer

Open JSON as a collapsible tree to explore nested objects and arrays. Everything you paste stays in your browser.

JSON Diff

Compare two JSON documents by structure, not text: see every added, removed and changed value with its path, ignoring key order.

Convert Unix epoch timestamps to dates and dates to timestamps, in seconds or milliseconds, in UTC and your local time.

Where the numbers come from

These tools load no outside data. Everything they show is computed in your browser from what you paste, following published standards: RFC 8259 for JSON, RFC 7519 for JSON Web Tokens, RFC 4648 for Base64, RFC 3986 for URL encoding, RFC 9562 for UUIDs, FIPS 180-4 and RFC 1321 for hashes, the YAML 1.2.2 specification, MDN’s guide to JavaScript regular expressions and the crontab(5) manual page. Three tools use MIT-licensed libraries served from this site: js-yaml, sql-formatter and js-beautify. Each tool is checked against a suite of known test vectors, and the site is reviewed whenever a cited standard or library changes or a reader reports an error. The site is maintained by Quick JSON Tools. The methodology page explains how each tool works and what runs where.
