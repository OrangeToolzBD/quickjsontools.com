JSON to CSV Converter

To convert JSON to CSV, paste an array of objects and press JSON → CSV: each object becomes a row and each key a column, with nested fields flattened to names like address.city. Values containing commas, quotes or line breaks are quoted as RFC 4180 (October 2005) describes. CSV → JSON works in reverse, all in your browser.

Updated September 20, 2026 · By Quick JSON Tools

How do I convert JSON to CSV?

Paste a JSON array of objects and press JSON → CSV, then Copy the result into a .csv file or a spreadsheet. The header row lists every key found in any object, in the order first seen. An object that lacks a key gets an empty cell in that column.

Worked example from the tool’s tests:

[{"a": 1, "b": {"c": "x,y"}}, {"a": 2, "d": true}]

becomes

a,b.c,d
1,"x,y",
2,,true

The nested field b.c became its own column, “x,y” was quoted because it contains a comma, and each row has an empty cell where it had no value.

Other details:

  • A single object, not wrapped in an array, is converted as one row.
  • Items that are not objects, such as plain numbers, go in a column named value.
  • Double quotes inside a value are doubled, so say "hi" becomes "say ""hi""", the escaping RFC 4180 specifies.
  • Choose comma, semicolon or tab as the delimiter if your spreadsheet expects something other than commas.
  • Rows are separated by line feeds. RFC 4180 describes CRLF line breaks, so if a program insists on them, convert the line endings in a text editor.

To get the CSV into Excel or another spreadsheet, save it as a .csv file and open it, or use the program’s text import so you can set column types. Import is the safer route when a column holds IDs with leading zeros or long numbers.

What happens to nested JSON?

Nested objects are flattened: each inner key becomes a column named with the full path joined by dots, such as address.city. Arrays are not expanded into extra rows or columns. An array inside a record is written into a single cell as JSON text, for example "[1,2]".

[{"name": "Ana", "address": {"city": "Lima", "geo": {"lat": -12}}, "tags": ["a", "b"]}]

name,address.city,address.geo.lat,tags
Ana,Lima,-12,"[""a"",""b""]"

The tags cell looks busy because the JSON quotes inside it are doubled, but it reads back correctly. This keeps one row per record, which is usually what you want for a spreadsheet. If you need one row per tag instead, split the array in code before converting:

// one row per tag
const rows = data.flatMap(r => r.tags.map(tag => ({ ...r, tags: undefined, tag })));

Before converting a large or unfamiliar document, look at its shape in the JSON viewer to decide which arrays need that treatment.

How do I convert CSV to JSON?

Paste CSV with a header row and press CSV → JSON. Each row becomes an object keyed by the header names. Quoted fields may contain commas, doubled quotes and line breaks. With “Detect numbers and true/false” ticked, plain numbers become numbers and true, false and null become JSON values.

The test case below shows the quoting and number handling:

name,age
"Doe, J",30
Ana,

[{"name": "Doe, J", "age": 30}, {"name": "Ana", "age": ""}]

Empty cells become empty strings, and fully blank lines are skipped.

Watch out for codes that look like numbers. With detection on, 007 becomes 7 and 02134 becomes 2134, which breaks ZIP codes, phone numbers and IDs. Untick the detection option to keep every value as a string. Detection only recognizes plain decimals, so a value such as 1e5 stays a string either way.

Pick the same delimiter the file uses; a semicolon-separated file read as comma-separated comes back as one column per row. To read the output comfortably, paste it into the JSON formatter.

Frequently asked questions

Can I convert JSON into CSV?

Yes, when the JSON is a list of similar records. Each record becomes a row and each key a column, with nested objects flattened into dotted column names. Deeply nested data with many arrays does not fit a flat table well, so reshape it in code first if you need one row per array item.

How can I convert a JSON file to a CSV file online?

Open the JSON file, copy its contents, paste them above, press JSON → CSV and then Copy. Paste the result into a text editor and save it with a .csv extension. The conversion happens in your browser, so the file is not uploaded anywhere.

How do I turn a JSON file into an Excel spreadsheet?

Convert the JSON to CSV here, save the output as a .csv file, and open it in your spreadsheet program. For columns such as ZIP codes or long IDs, use the program’s text import option and set those columns to text, so leading zeros and long numbers are kept.
