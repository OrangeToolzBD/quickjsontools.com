URL Encode and Decode

To URL decode a string, turn each % followed by two hex digits back into its byte, then read the bytes as UTF-8: %20 is a space, %3D is = and %C3%A9 is é. That percent-encoding is defined in RFC 3986 (January 2005). This tool encodes and decodes in your browser.

Updated September 20, 2026 · By Quick JSON Tools

How do I URL-encode a string?

Paste the text and press Encode. By default the tool encodes it as a single URL component, such as a query value, so every character with a special meaning in URLs is escaped. Letters, digits and - . _ ~ are never encoded, because RFC 3986 lists them as unreserved.

Worked example from the tool’s tests: a b&c=d/é encodes to a%20b%26c%3Dd%2F%C3%A9. The space, &, = and / are escaped, and é becomes two percent-encoded bytes because it takes two bytes in UTF-8.

To decode, paste the encoded text and press Decode. A % that is not followed by two hex digits, as in 100%, gives “Malformed percent-encoding”; write a literal percent sign as %25.

encodeURIComponent("a b&c=d/é")      // "a%20b%26c%3Dd%2F%C3%A9"
decodeURIComponent("%C3%A9")          // "é"

# Python
from urllib.parse import quote, unquote
quote("a b&c=d/é", safe="")           # 'a%20b%26c%3Dd%2F%C3%A9'
unquote("%C3%A9")                     # é

Encoding twice is a common bug: % becomes %25, so %20 turns into %2520. If you see %25 sequences, decode once more.

encodeURI vs encodeURIComponent

encodeURIComponent is for a piece of a URL, such as one query value: it escapes everything that could change the URL’s structure. encodeURI is for a complete URL: it leaves characters such as : / ? & = # alone so the URL still works. The “Encode as a whole URL” option switches the tool to encodeURI.

InputComponent (default)Whole URL
Jack & JillJack%20%26%20JillJack%20&%20Jill
https://example.com/?q=a b&c=dhttps%3A%2F%2Fexample.com%2F%3Fq%3Da%20b%26c%3Ddhttps://example.com/?q=a%20b&c=d

MDN’s encodeURIComponent reference (updated October 30, 2025) notes that it leaves only letters, digits and - _ . ! ~ * ' ( ) unescaped, while encodeURI also keeps characters such as ; , / ? : @ & = + $ #.

The rule of thumb: build URLs from parts and encode each value with encodeURIComponent. Running encodeURI over a value that contains & or = leaves them in place, so “Jack & Jill” would split into two query parameters.

const url = "https://example.com/search?q=" + encodeURIComponent(userInput);
// or let the browser do it:
const u = new URL("https://example.com/search");
u.searchParams.set("q", userInput);

Why is a space encoded as %20 or +?

Percent-encoding, as RFC 3986 defines it, writes a space as %20. The + for space comes from HTML form encoding (application/x-www-form-urlencoded), used in query strings submitted by forms. RFC 3986 gives + no special meaning; it is simply a reserved character.

So both appear in real URLs, and which one you get depends on what produced the URL. When decoding a form-style query string, tick “Treat + as a space”. The tool’s test shows the difference: a+b%20c decodes to a b c with the option on, and to a+b c with it off.

The tool always encodes a space as %20, which every server accepts. MDN suggests replacing %20 with + when you need form-style output. In form data, a literal plus sign must be sent as %2B, or it will arrive as a space.

Percent-encoding is only for URLs. To put text inside a JSON value, escape it with the JSON stringify tool instead.

Frequently asked questions

What is %3D in a URL?

%3D is the percent-encoded equals sign (=). Equals separates names from values in a query string, so an = that belongs to a value is encoded as %3D to avoid confusion. Base64 padding inside a URL is a common source. Decoding turns it back into =.

How do I manually decode a URL?

Replace each %XX with the byte whose hex value is XX, then read the bytes as UTF-8. %41 is A, and %C3%A9 is the two bytes of é. For form data, change + to a space first. Pasting the URL here and pressing Decode does the same.

How do I decrypt an encoded URL?

There is nothing to decrypt. Percent-encoding is not encryption; it only makes characters safe to use in a URL, and anyone can reverse it without a key. Paste the URL and press Decode to read it. If the decoded text still looks scrambled, it may be Base64 or genuinely encrypted data.

What is URL decoding used for?

Reading values from query strings and paths, debugging redirect and tracking links, and inspecting parameters in server logs, where special characters appear encoded. If a decoded value is itself Base64, continue with the Base64 decoder. Decode only once, unless you can see %25 sequences.
