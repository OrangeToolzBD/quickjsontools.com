JSON Stringify and Escape

Use this JSON stringify online tool to turn any text into an escaped JSON string, parse an escaped string back to plain text, or minify JSON to one line. Quotes, backslashes and control characters are escaped as RFC 8259 requires, using the same JSON.stringify your JavaScript code runs, locally in your browser.

Updated September 20, 2026 · By Quick JSON Tools

What does JSON.stringify do?

JSON.stringify converts a JavaScript value into JSON text. Objects and arrays become JSON syntax, strings are wrapped in double quotes with special characters escaped, and values JSON cannot represent are dropped or replaced. An optional third argument adds indentation.

MDN’s reference (updated August 28, 2026) lists the edge cases that catch people out:

  • undefined, functions and symbols are left out of objects and become null inside arrays.
  • NaN and Infinity become null.
  • BigInt values and circular references throw a TypeError.
  • Dates are written as ISO strings through their toISOString method.
  • A numeric indent is capped at 10 spaces.
JSON.stringify({ a: undefined, b: [undefined, NaN], c: new Date(0) })
// '{"b":[null,null],"c":"1970-01-01T00:00:00.000Z"}'
JSON.stringify("say \"hi\"")
// '"say \"hi\""'

On this page, Stringify treats whatever you paste as one string and returns it as a JSON string literal. That is what you need to embed text, or a whole JSON document, inside another JSON value.

How do I escape quotes and newlines in JSON?

Inside a JSON string, write a double quote as \", a backslash as \\, a newline as \n, a carriage return as \r and a tab as \t. RFC 8259 requires escaping quotation marks, backslashes and control characters U+0000 to U+001F; any other character may appear as-is or as a \u escape.

Paste the raw text and press Stringify to have it done for you. For example, these two lines:

line one
line "two"

become

"line one\nline \"two\""

Characters outside ASCII, such as é, and the forward slash are left unescaped, which is valid JSON. Common mistakes: escaping a single quote (\' is not a JSON escape), leaving Windows paths with single backslashes, and pasting multi-line text into a string without escaping the line breaks. The JSON validator flags all three.

How do I unescape a JSON string?

Paste the escaped string, including its outer double quotes, and press Parse a JSON string back. The tool runs JSON.parse and returns the plain text, with \n turned back into real line breaks and \" into quotes. If the input parses to something other than a string, the tool says so.

This is handy for double-encoded JSON, where a JSON document was stored as a string inside another document, as in log lines or message queues:

"{\"id\":7,\"ok\":true}"          ← escaped string
{"id":7,"ok":true}                ← after "Parse a JSON string back"

Paste the result back in and press Minify JSON to one line, or open it in the JSON formatter to read it. In code, the same unwrapping is two parses:

const inner = JSON.parse(JSON.parse(escaped));   // JavaScript
inner = json.loads(json.loads(escaped))          # Python

Frequently asked questions

What is the difference between JSON.stringify and toString?

JSON.stringify produces JSON text that can be parsed back, with quoted strings and nested structure intact. An object’s default toString returns "[object Object]", and an array’s joins its items with commas, losing quotes and nesting. Use JSON.stringify whenever the output must be read by another program.

How do I convert a stringified JSON back into an object?

Call JSON.parse on it in JavaScript or json.loads in Python. If the result is still a string that starts with { or [, the JSON was encoded twice, so parse it once more. The Parse button on this page performs one level of unwrapping.

Does JSON.stringify escape Unicode characters?

No. Characters such as é stay as they are, which is valid because JSON text is UTF-8. Only quotes, backslashes and control characters must be escaped. If a system needs pure ASCII, it has to convert other characters to \u escapes itself.
