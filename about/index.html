About Quick JSON Tools

Quick JSON Tools is a set of free developer utilities that run entirely in the browser, so pasted data is never uploaded.

Quick JSON Tools is a set of free utilities for everyday developer chores: formatting and validating JSON, comparing text and data, testing regular expressions, decoding JSON Web Tokens, and converting between common formats and encodings.

The site exists because much of what developers paste into web tools is sensitive: API responses with customer data, configuration files, access tokens, internal queries. Every tool here does its work in your browser. What you paste is not uploaded, logged or stored, and you can confirm that by watching the Network tab in your browser’s developer tools while you use a tool.

The tools aim to be precise rather than clever. Each one follows a named standard or a documented library, reports errors with enough detail to fix them, and says plainly what it does not do. The JWT decoder, for example, decodes tokens but never claims to verify a signature.

The site is run by Quick JSON Tools.

Corrections. If a tool gives a wrong result, or a page misstates a standard, please report it through the contact page with the input you used and the output you expected. Confirmed errors are fixed, a test case is added so the mistake cannot return, and the page is updated. The methodology page describes how each tool is built.
