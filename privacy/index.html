Privacy policy

Last updated September 20, 2026.

Everything you paste or type into these tools is processed in your browser. It is not sent to us or to anyone else, it is not stored, and it is never added to the page address. The Copy buttons copy the tool’s output to your own clipboard only.

Analytics, advertising and partners

Analytics. This site does not currently run Google Analytics or any other visitor-tracking service. If that changes, this page will be updated first to name the service, what it collects and how to opt out.

What you paste into the tools. The tools process your input in your browser. The tool code makes no network requests, sends nothing you type to this site’s server, and does not save your input. The tools on this site have no “Copy link to this result” button, so your input is never placed into a link. The Copy buttons copy a tool’s output to your own clipboard and nowhere else. You can confirm all of this in the Network tab of your browser’s developer tools.

Advertising and partners. There is no advertising on this site at launch, and no affiliate or other partners. Before any are added, this page will be updated to name each provider, what it collects and how to opt out.
