Hash Generator

A hash generator computes a fixed-length fingerprint of your text. This one shows MD5, SHA-1, SHA-256, SHA-384 and SHA-512 at once, hashing the text as UTF-8. The SHA family comes from your browser’s Web Crypto API and is specified in FIPS 180-4 (August 2015); MD5 is computed in JavaScript.

Updated September 20, 2026 · By Quick JSON Tools

What is a hash?

A cryptographic hash turns input of any length into a short, fixed-size value. The same input always gives the same hash, and any change, even one character, gives a completely different one. NIST’s standard says digests are used to detect whether messages have changed since the digests were generated.

Paste text and press Generate hashes. The tool’s test vectors for the input abc:

AlgorithmHash of “abc”
MD5900150983cd24fb0d6963f7d28e17f72
SHA-1a9993e364706816aba3e25717850c26c9cd0d89d
SHA-256ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad

The MD5 value matches the test suite in RFC 1321 (April 1992). Hashes are exact, so check the input when results differ: a trailing newline or space changes everything. On the command line, use printf rather than echo, which adds a newline:

printf 'abc' | sha256sum
printf 'abc' | md5sum

# Python
import hashlib
hashlib.sha256("abc".encode()).hexdigest()

SHA-256 vs MD5

SHA-256 produces a 256-bit hash and is a current standard. MD5 produces a 128-bit hash and is broken for security: collisions, two inputs with the same hash, can be found cheaply. Use MD5 only for non-security checksums, and SHA-256 or stronger for anything that matters.

RFC 6151 (March 2011) states MD5 is no longer acceptable where collision resistance is required, such as digital signatures. NIST announced on December 15, 2022 that SHA-1 will be retired by December 31, 2030, because practical collision attacks exist. The Web Crypto API offers no MD5 at all, as MDN’s digest reference (updated December 28, 2025) shows, which is why the tool includes its own implementation.

Can a hash be reversed?

No. A hash discards information, so there is no way to compute the input from the output. Sites that claim to “decrypt” MD5 are looking the hash up in lists of known inputs, which works only for short or common strings. That is exactly why fast hashes are unsafe for passwords.

The OWASP Password Storage Cheat Sheet says fast algorithms such as SHA-256 are not suitable for passwords because attackers can try guesses quickly. It recommends Argon2id first, then scrypt, bcrypt for legacy systems, and PBKDF2 where FIPS-140 compliance is required. Those are slow, salted functions; this tool computes none of them and is not a password-hashing tool.

Never paste a real password or secret into any online hash tool. This page hashes in your browser and sends nothing, but a hash of a weak password can be looked up just like the MD5 examples above. For random identifiers rather than fingerprints, use the UUID generator; to encode rather than hash, use Base64.

Frequently asked questions

What is a hash generator?

A hash generator is a tool that runs text through hash functions such as SHA-256 and shows the results as hex strings. People use one to verify downloads against published checksums, compare data without storing it, and check what a library should output.

How do you generate a hash?

Paste the text above and press Generate hashes to see five algorithms at once. In code, browsers offer crypto.subtle.digest("SHA-256", bytes), Python has the hashlib module, and most systems ship sha256sum. Whatever you use, make sure every tool hashes exactly the same bytes, including the text encoding and line endings.

How can I generate a SHA-256 hash?

Enter your text here and read the SHA-256 line; for abc it begins ba7816bf and ends f20015ad. On Linux, run printf 'abc' | sha256sum, which avoids the newline echo would add. In Python, use hashlib.sha256(data).hexdigest(). All three should give the same 64-character hex string for the same bytes.
