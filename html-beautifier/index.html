HTML Beautifier

An HTML beautifier re-indents markup so nested elements are easy to follow. This one runs the MIT-licensed js-beautify HTML formatter in your browser with a 2- or 4-space indent, and its Minify button removes the whitespace between tags. Nothing you paste is uploaded.

Updated September 20, 2026 · By Quick JSON Tools

How do I format HTML?

Paste the HTML, pick 2 or 4 spaces and press Beautify. Block elements move onto their own lines, indented under their parents, while short inline content stays on the line with its element.

Example, run through js-beautify 1.15.4 with a 2-space indent:

<div><p>Hello</p><ul><li>One</li><li>Two</li></ul></div>

<div>
  <p>Hello</p>
  <ul>
    <li>One</li>
    <li>Two</li>
  </ul>
</div>

Content inside a pre element keeps its original spacing, because there the spaces are part of the content.

The beautifier does not check that your HTML is valid; it reformats what it is given. If the page says the beautifier library is not loaded, the page is missing its vendored copy; nothing is fetched from elsewhere.

For XML-based markup such as SVG or sitemaps, the XML formatter also checks that tags pair up.

Does minifying HTML speed up a page?

A little. Minifying removes characters the browser does not need, so the file is smaller. But servers usually compress HTML with gzip or Brotli, which already shrinks repeated whitespace, so minification adds a smaller gain on top. Do both for production pages, and keep the readable source for editing.

A web.dev guide (updated December 11, 2023) says compression reaches 70–90% on larger files and that minification is an additive optimization rather than one compression makes pointless.

This tool’s Minify (whitespace) button is deliberately simple: it removes whitespace between a closing > and the next <, and trims the ends. It does not remove comments, shorten attributes or touch inline CSS and JavaScript.

<div>
  <p>Hello</p>
</div>

<div><p>Hello</p></div>

Be careful with inline content. MDN’s whitespace guide explains that whitespace between inline elements is collapsed but still rendered as a space. Removing it can join words or close gaps between buttons and links, so check the page after minifying. It also applies inside pre elements, where whitespace between tags is part of the content.

Why does my HTML indentation look wrong?

Usually because the markup is not nested the way it looks. An unclosed div, a stray closing tag, or a block element inside a p all shift the indentation of everything after them. The beautifier is showing you the structure it found, which is often the clue to the bug.

Browsers repair broken markup silently, so a page can look fine while its source is not. MDN’s whitespace guide (updated December 15, 2025) also explains why spacing in the browser does not always match the source.

Things to check:

  • Every opening tag you expect to close has a matching closing tag.
  • Block elements such as div or ul are not inside a p; the browser closes the p early.
  • Inline elements such as span and a keep their content on one line, which is intended.
<p>Intro
  <div>Block</div>   <!-- a p cannot contain a div: the p ends before it -->
</p>

To see exactly what changed after a cleanup, paste the before and after into the diff checker.

Frequently asked questions

How can I beautify my HTML code?

Paste it above, choose a 2- or 4-space indent and press Beautify, then Copy the result back into your file. For a whole project, run the same js-beautify library from the command line or use your editor’s format command, so every file follows one style and reviews show only real changes.

How do I make HTML look pretty?

Indent nested elements consistently, put block elements such as div, ul and table on their own lines, and keep short inline content together. A beautifier applies those rules automatically. Consistent attribute quoting and lowercase tag names help too, and so does closing every element you open.

Is minified HTML harder to debug?

Yes, which is why you minify only the copy you deploy and keep the readable source for editing. Browser developer tools show the parsed page structure regardless of how the file was written, and you can paste minified markup here and press Beautify to read it again.
